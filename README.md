# Студия мебели

[Открыть сайт](https://rto2311ud-stack.github.io/walenza-studio/)

Каталог мебели и 3D-конструктор с предварительной стоимостью до ввода контактов, ручной расстановкой шкафов, индивидуальными размерами, антресолями, отдельным цветом корпуса, ссылкой на проект и сохранением PNG. Пять образов кухни имеют разные композиции, адаптируемые к размерам помещения.

В репозитории опубликована готовая статическая сборка. Форма готовит письмо на krasnayaploshchad@mail.ru, которое посетитель отправляет в своём почтовом приложении. Автоматическая отправка и кабинет администратора требуют отдельного серверного размещения.

Доплата за корпус EGGER и компакт-плита Arcobaleno 12 мм рассчитываются по подтверждённым данным прайсов. Камень показывается только в 3D и исключён из суммы. Неподтверждённые ставки, нестандартные модули и дополнительные работы перечислены отдельно: показанная сумма не является окончательной ценой всей кухни.
